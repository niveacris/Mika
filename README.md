# Mika
Desenho infantil
Descrição Base dos Personagens 
Mika: pequena raposa azul, olhos grandes e expressivos, pelo macio, cachecol amarelo, aparência amigável e carismática, estilo animação 3D infantil cinematográfica, cores vibrantes.
Pipo: pequeno vaga-lume amarelo brilhante, olhos divertidos, asas translúcidas, aparência fofa e amigável.
Lumi: pequena estrela dourada com rosto sorridente, olhos brilhantes, emitindo partículas mágicas douradas.
Animação 3D infantil cinematográfica, qualidade de filme de animação, personagens extremamente fofos e expressivos, iluminação mágica, cores vibrantes, cenário encantado, riqueza de detalhes, atmosfera acolhedora para crianças, profundidade de campo suave, luz volumétrica, composição cinematográfica, sem texto, sem marcas d'água, preenchendo toda a cena.
